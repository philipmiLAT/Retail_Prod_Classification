
# AI-Powered Retail Product Classification

## Project Overview
A machine-learning application that classifies retail
products from uploaded images and displays a predicted
category and confidence score.

## Team
Team Ritesh - Five-member internship project.

## Technology
- Python
- TensorFlow / Keras
- MobileNetV2
- Streamlit
- Google Colab
- GitHub

## Repository Structure
- src/retail_clf/ - Shared Python modules
- app/ - Streamlit application
- notebooks/ - Data and model experiments
- data/ - Dataset files
- models/ - Trained model artifacts
- reports/ - Evaluation results
- logs/ - Runtime logs
- tests/ - Automated tests
- docs/ - Project documentation

## Current Status
Repository setup and initial development.

## Dataset
Retail Products Classification dataset.
Dataset access and reuse permissions are being verified.

## Goal
Classify product images into 4-6 selected categories.
